Generate complete forensic investigation reports from the CERT portal: automatic evidence collection, customizable sections, local AI enrichment (Ollama), and HTML / Markdown export.

UI access

  • Sidebar Forensic reports — full generator (template, custom blocks, preview, export)
  • From an incident — Generate report button (pre-fills case_id / incident)

Recommended workflow

  1. Identify the case_id (incident, upload, Timesketch sketch)
  2. Collect evidence — MinIO uploads, OpenSearch events, IOC/TI, alerts, aggregations
  3. Pick a template: standard-ir, executive-brief, technical-deep
  4. Add custom blocks (business context, decisions, contacts)
  5. Optional: Enrich with local AI (Ollama) for narrative summary and recommendations
  6. Edit the draft, then export as HTML or Markdown

REST API

MethodRoutePurpose
GET/api/reports/templatesAvailable templates
GET/api/reports/llm/statusOllama status / heuristic fallback
POST/api/reports/collectEvidence collection (case_id or incident_id)
POST/api/reports/generateCreate report + sections
PUT/api/reports/:idUpdate draft
POST/api/reports/:id/enrichRe-run AI enrichment
GET/api/reports/:id/export?format=html|md|jsonFinal export

CERT session required (cookie). Full guide: docs/PORTAL/FORENSIC-REPORTS.md.

Local AI (Ollama)

  • Env: OLLAMA_URL, OLLAMA_MODEL (default llama3.2)
  • If Ollama is unavailable, the engine uses heuristic enrichment (same section structure)
  • Data stays on local infrastructure — no third-party cloud

Verification

python scripts/forensic_report_verify.py — templates, collect on CASE-UC01-RANSOM, generate and JSON export.
