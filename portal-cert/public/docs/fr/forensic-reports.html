Génération de rapports d'investigation forensic complets depuis le portail CERT : collecte automatique des preuves, sections personnalisables, enrichissement IA locale (Ollama) et export HTML / Markdown.

Accès UI

  • Menu latéral Rapports forensic — générateur complet (modèle, blocs libres, aperçu, export)
  • Depuis un incident — bouton Générer le rapport (pré-remplit case_id / incident)

Workflow recommandé

  1. Identifier le case_id (incident, upload, sketch Timesketch)
  2. Collecter les preuves — uploads MinIO, événements OpenSearch, IOC/TI, alertes, agrégations
  3. Choisir un modèle : standard-ir, executive-brief, technical-deep
  4. Ajouter des blocs personnalisés (contexte métier, décisions, contacts)
  5. Optionnel : Enrichir avec l'IA locale (Ollama) pour synthèse narrative et recommandations
  6. Éditer le brouillon, puis exporter en HTML ou Markdown

API REST

MéthodeRouteRôle
GET/api/reports/templatesModèles disponibles
GET/api/reports/llm/statusÉtat Ollama / fallback heuristique
POST/api/reports/collectCollecte preuves (case_id ou incident_id)
POST/api/reports/generateCréation rapport + sections
PUT/api/reports/:idMise à jour brouillon
POST/api/reports/:id/enrichRé-enrichissement IA
GET/api/reports/:id/export?format=html|md|jsonExport final

Session CERT requise (cookie). Doc détaillée : docs/PORTAL/FORENSIC-REPORTS.md.

IA locale (Ollama)

  • Variables : OLLAMA_URL, OLLAMA_MODEL (défaut llama3.2)
  • Si Ollama est indisponible, le moteur utilise un enrichissement heuristique (même structure de sections)
  • Les données restent sur l'infrastructure locale — pas d'envoi vers un cloud tiers

Vérification

python scripts/forensic_report_verify.py — templates, collecte sur CASE-UC01-RANSOM, génération et export JSON.
