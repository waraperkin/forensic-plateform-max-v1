Le Sekoia Control Center (v2.1) est le centre de pilotage complet de votre SIEM Sekoia.io : inventaires éditables, monitoring d'ingestion temps réel, recherche d'événements, fédération CTI et automatisation CERT — bien au-delà des fonctionnalités de la console Sekoia standard.

Monitoring d'ingestion

La plateforme ingère une télémétrie locale dans OpenSearch (forensic-sekoia-telemetry-*) qui alimente :

  • Volumétrie par intake, par source et par log.hostname sur des fenêtres de 1 h à 7 j ;
  • Top hostnames par intake avec date du dernier événement ;
  • Alertes automatiques : chute de volumétrie, intake muet, hostname absent, anomalie d'ingestion ou de parsing ;
  • Acquittement des alertes par fingerprint, tracé dans l'audit ;
  • Dashboard Grafana dédié Sekoia Ingestion (volumes, eps, alertes).

API interne

Toutes les actions du Control Center passent par l'API interne du portail (/api/sekoia/*), documentée dans docs/SEKOIA.md :

RouteUsage
GET/POST /api/sekoia/intakes, PATCH/DELETE /api/sekoia/intakes/:uuidCRUD intakes
GET/POST /api/sekoia/rules, PATCH/DELETE /api/sekoia/rules/:uuidCRUD règles
GET/POST /api/sekoia/playbooks, PATCH/DELETE /api/sekoia/playbooks/:uuidCRUD playbooks
POST /api/sekoia/intakes/bulk, /api/sekoia/rules/bulkActivation / désactivation en masse
POST /api/sekoia/events/searchRecherche d'événements (job Lucene)
GET /api/sekoia/local/timeseries, /api/sekoia/local/top-hostnamesVolumétrie locale
POST /api/sekoia/cti/iocRecherche IOC fédérée OpenCTI + MISP + OpenSearch
POST /api/sekoia/cti/ioc/thehive-case, /api/sekoia/cti/ioc/cortexPivots TheHive / Cortex
POST /api/sekoia/logformat/detectDétection de format de log
GET /api/sekoia/coverageMatrice de couverture formats × règles

Prérequis

  • SEKOIA_API_KEY (droits lecture + écriture sur intakes / règles / playbooks) dans .env ;
  • Connecteurs CTI optionnels : OPENCTI_TOKEN, MISP_KEY, THEHIVE_API_KEY, CORTEX_API_KEY — les sources non configurées sont simplement marquées « non configuré » ;
  • Validation de bout en bout : ./scripts/validate-sekoia.sh.
